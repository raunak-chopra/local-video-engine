# General-purpose text design specimen

Asset-free v2 example of a project title, an interview lower third, and explicit
Hindi/English text runs. The named speaker is fictional sample copy. Its teal
palette, speech-friendly roles and symmetric insets belong only to this example.
No cooking or Blame Raunak rules are global engine defaults.

Use `npm.cmd run video -- still projects/text-design-study/project.json
--frame=225 --canvas=square` on one line. Review vertical/square/landscape
separately. `project.json` is the only render clock. No audio is declared.
