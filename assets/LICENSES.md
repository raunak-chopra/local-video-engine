# Asset license log

Standing statement from the owner (2026-10-13): every file placed in `assets/`
or handed to the agent is licensed or otherwise cleared for use in this
project. The agent does not re-ask about permission for supplied assets.

This log keeps each license traceable later. Add one row per item or per pack.
Any source counts: Envato Elements, other stock sites, own footage, own
recordings, purchased fonts, commissioned work, free or open licenses.

## Source and license types

- **Envato Elements**: record the item ID or URL. Register the item for the
  project in Envato if the subscription requires it.
- **Other stock or marketplace** (Artlist, Epidemic, Storyblocks, Pexels,
  Pixabay and similar): record the URL and the license name.
- **Fonts**: record the foundry and license, including web or video use.
- **Open source and free** (OFL, CC0, CC-BY): record the license. CC-BY needs
  an attribution line, so add it in Notes.
- **Own or commissioned**: record the owner. Keep any release for people who
  appear on camera.
- **Whisper models and local tools**: MIT or similar open licenses. No
  subscription or attribution file is needed.
