# Scene and look plan

Use this as a planning artifact beside a brief, not as executable brief fields.
Continue the authorized task after planning unless the user requests an approval gate.

```text
Purpose, audience, intended takeaway, exact CTA:
Approved copy, claims/evidence, asset paths, missing placeholders:
Deliverables: supported formats, final frame count, approved audio policy:
Look: palette, font/weights, type hierarchy, spacing, safe area, reference properties:
Motion: primary action, chosen spring/easing, rhythm, deliberate pauses:

For each shot:
- Purpose and exact content; supported kind or smallest custom extension.
- One idea and a deliberate on-screen word budget; which approved visual explains it.
- Composition and focal point; how the layout changes for each requested format.
- Entry, readable hold, exit in frames; global timing including overlap.
- Transition and continuity: which object persists, or why a cut helps the story.
- Audio/caption cue on the final timeline; supplied timing evidence or no audio.
- Frames to inspect; acceptance based on observable behavior.

Save the plan, then calculate the timeline with npm run review.
Prototype one custom scene, inspect it, and build the rest.
Log defects and fixes rather than assigning unsupported quality scores.
```
